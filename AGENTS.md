# Agent Instructions

For MiniPdf rendering or visual benchmark contributions, read and follow `.claude/skills/minipdf-contribution/SKILL.md`.
# Agent Guidelines

- Use English.
- Do not use emojis.
- Compare behavior with the default branch when relevant.
- Never mark work complete before proving it works.
- Keep changes simple, focused, and minimal.
- Find and fix root causes; do not use temporary workarounds.
- Maintain senior-engineer quality without overengineering simple problems.
- Challenge and review your work before presenting it.
